Para ejecutar el código, es necesario clonar el repositorio para abrirlo por un editor de código, se debe ejecutar el main.cpp. En dado caso de no ser posible, los archivos esenciales para la ejecución son el main.cpp y el supet.csv.
En main.cpp está todo el código final, ahí está todo el programa. Usamos un git push desde replit (https://replit.com/@Maracuya/Proyecto-de-programacion), y añadimos todos los archivos que existían en esa carpeta.
